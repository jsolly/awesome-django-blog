The following sites have estimated the value of my domain, blogthedata.com. These values were all gathered on 3/11/22

<a target="_blank" rel="noopener noreferrer" href="https://www.godaddy.com/domain-value-appraisal/appraisal/?checkAvail=1&amp;domainToCheck=blogthedata.com">Godaddy Domain Appraisal </a> \- $1,320

<a target="_blank" rel="noopener noreferrer" href="https://www.estibot.com/appraise?a=get&amp;id=8161382&amp;domain=blogthedata.com">Estibot</a> - Less than $100

Godaddy.com has an <a target="_blank" rel="noopener noreferrer" href="https://www.youtube.com/watch?v=SNukqlGstqs">excellent video</a> on how to price and sell domains. Several factors affect domain name value including: length, pronounceability, sales of domains with similar keywords, whether it is a .com or .net (and more).

Did you know that no one owns a domain, but they are leased by domain name registrars <a target="_blank" rel="noopener noreferrer" href="https://www.icann.org/en/accredited-registrars">acredited by ICANN</a>.

I don’t think blogthedata.com is worth what the Godaddy estimator thinks it is. Who knows!
